# 课程说明与学习安排

> 最近整理：2026-10-01。日期表示本站内容维护时间，课程年份保留所收录的历史版本；全部外链尚未逐一验证。

本页用于理解课程之间的关系、安排学习顺序和记录学习关注点。课程网站、视频、教材与实验链接集中维护在 [AI / CS 资源索引](ai_map.md)；原有资源已保留在索引中。

下面是本站的学习安排建议，正式先修要求与教学内容请以课程页面为准。可以先选一门编程入门课，配合命令行练习，再进入算法、人工智能与机器学习；每个阶段结合自己的基础选课。

## Intro

### Crash Course

约 8 个小时的 Computer Science 系列介绍计算机历史、计算机的运作方式、主要模块与计算机科学中的基本思想，适合先建立全局认识。

### Harvard - CS50

将编程实践与计算机科学入门结合起来学习。可以通过小程序、作业与个人项目检查自己是否理解每个主题。

资源：[Intro 课程与视频](ai_map.md?id=intro)。

## Programming

### Harvard - CS50 Python

学习关注：用 Python 组织程序、处理输入输出，并通过练习积累编程经验。

### MIT - 6.100A (formerly 6.0001)

Introduction to Computer Science Programming in Python。学习时结合课程中的计算思维与编程练习；索引同时保留 6.100A+B 网站和旧编号 6.0001 的 OCW 历史资料。

### Berkeley - CS61A

Structure and Interpretation of Computer Programs。学习关注：抽象、程序结构与解释程序的运行过程；教材可配合作业阅读。

### Stanford - CS106A

Programming Methodology。可作为另一条编程入门路线，与自己的语言基础和课程资源安排相结合。

### CMU - 15-112

Fundamentals of Programming。索引保留课程入口与 Kosbie Spring 2023 的历史资源，选择版本后配套使用讲义和练习。

资源：[Programming 课程、教材与实验](ai_map.md?id=programming)。

## Command Line

### MIT - Missing semester

The Missing Semester of Your CS Education。可在学习编程时同步练习开发工具的使用，把操作过程写成可以重复执行的笔记。

### Shell

The Art of Command Line 与 The Shell Scripting Tutorial 可配合使用；练习时关注命令组合、输入输出和脚本，而不仅是记住命令名称。

资源：[Command Line 课程与教程](ai_map.md?id=command-line)。

## Algorithm

### MIT - 6.006 / 6.121

Introduction to Algorithms。学习关注：用清楚的语言解释算法、分析复杂度，并实现与测试典型算法。

### MIT - 6.046J

Design and Analysis of Algorithms。可在算法基础之后继续学习，练习把设计思路写成论证。

### CMU 15-451/651

Algorithm Design and Analysis。可与其他算法课程对照，选择一套版本作为学习主线。

资源：[Algorithm 课程与历史版本](ai_map.md?id=algorithm)。

## AI

### Harvard - CS50-AI

CS50's Introduction to Artificial Intelligence with Python。学习时把算法与程序实验联系起来，记录一个问题为什么适合采用某种方法。

### Berkeley - CS188

Introduction to Artificial Intelligence。可作为人工智能基础课程的另一条路线，与资源索引中的其他课程比较后选择。

### CMU - 15-281

Artificial Intelligence: Representation and Problem Solving。学习关注：问题表示、求解方法以及方法的适用条件。

资源：[AI 课程与实验](ai_map.md?id=ai)。

## Machine Learning

### Stanford - CS229: Machine Learning

学习关注：把数学表达、算法实现和实验结果对应起来。使用作业参考资料时，先独立完成自己的推导与实现。

### Berkeley - CS189/289A

Introduction to Machine Learning。索引保留多个课程入口；选择学期后，以对应版本的课程安排为准。

### CMU - 10-315

Introduction to Machine Learning (SCS majors)。比较 CMU 的不同机器学习入门课时，可参考资源索引末尾保留的课程选择说明。

### MIT - 6.036

Introduction To Machine Learning。索引保留 Fall 2020 OCW 和 Open Learning Library 入口，适合按一个版本连续学习。

资源：[Machine Learning 课程](ai_map.md?id=machine-learning) · [CMU 课程选择说明](ai_map.md?id=how-to-choose-an-intro-ml-course-at-cmu)。

## Deep Learning

### Berkeley - CS182/282A

Deep Neural Networks。索引同时保留 Spring 2023 与 Fall 2023 的课程和视频，学习时配套使用同一学期的资料。

### CMU - 11-485/785

Introduction to Deep Learning。学习关注：模型训练、实验记录与结果分析。

### CMU - 10-417/617

Intermediate Deep Learning。完成基础课程后，可根据课程要求继续学习更深入的主题。

资源：[Deep Learning 课程、视频与历史版本](ai_map.md?id=deep-learning)。

## Computer Vision

### CMU - 16-385

Computer Vision。可结合图像实例理解视觉问题，并把基础概念与实际处理过程联系起来。

### Michigan - EECS 498.008 / 598.008

Deep Learning for Computer Vision。索引保留 Winter 2022 课程与已有视频入口；学习时留意资源的版本年份。

资源：[Computer Vision 课程与实验](ai_map.md?id=computer-vision)。

## Advanced

选定一个主题后，把学习目标写具体，例如完成一个小项目、复现一个实验，或写清楚一种方法的推导。

资源：[ML 进阶路线图](ai_map.md?id=advanced)。

## More

Python for Everybody（PY4E）可作为补充编程路线；Deep Learning Drizzle 可用于查找更多机器学习资料。资料检索入口统一保留在 [More](ai_map.md?id=more)。

## UC Berkeley

### CS 88 / DATA C88C: Computational Structures in Data Science

作为数据科学相关的计算基础课程加入候选列表。资源见 [UC Berkeley](ai_map.md?id=uc-berkeley)；该索引也保留 CS61B 的课程网站使用说明。

## MIT

### MIT - 6.100B (formerly 6.0002)

Introduction to Computational Thinking and Data Science。可在编程基础后继续学习，结合 6.100A+B 的课程安排使用。

### MIT - 6.100L (formerly 6.0001, full semester version of 6.100A)

完整学期版本的 Introduction to CS and Programming using Python。与半学期版本比较后，选择适合自己的学习节奏。

资源：[MIT 补充课程](ai_map.md?id=mit)。
