# Course Guide and Study Plan

> Last reviewed: 2026-10-01. This date records maintenance of this site; course years refer to the historical editions collected here. Not every external link has been checked individually.

Use this page to understand how courses relate to one another, plan a study sequence, and record what to focus on. Course websites, videos, textbooks, and lab links are maintained in the [AI / CS Resource Index](ai_map.md), which retains the original resources.

The suggestions below are this site's study plan; consult each course page for its official prerequisites and syllabus. Start with an introductory programming course and command-line practice, then move on to algorithms, artificial intelligence, and machine learning. Choose courses at each stage to match your background.

## Intro

### Crash Course

This roughly 8-hour Computer Science series introduces the history of computing, how computers work, their main components, and fundamental ideas in computer science. It is a useful way to build an overview first.

### Harvard - CS50

Learn introductory computer science alongside practical programming. Use small programs, assignments, and a personal project to check your understanding of each topic.

Resources: [Introductory courses and videos](ai_map.md?id=intro).

## Programming

### Harvard - CS50 Python

Focus on organizing programs in Python, handling input and output, and building programming experience through exercises.

### MIT - 6.100A (formerly 6.0001)

Introduction to Computer Science Programming in Python. Combine the course's computational thinking with its programming exercises. The index includes both the 6.100A+B website and historical OCW materials under the old 6.0001 number.

### Berkeley - CS61A

Structure and Interpretation of Computer Programs. Focus on abstraction, program structure, and explaining how programs run. Read the textbook alongside the assignments.

### Stanford - CS106A

Programming Methodology. This offers another introductory programming route; consider your experience with the language and how the course resources fit your schedule.

### CMU - 15-112

Fundamentals of Programming. The index retains the course website and Kosbie's Spring 2023 resources. Choose an edition and use its corresponding lectures and exercises together.

Resources: [Programming courses, textbooks, and labs](ai_map.md?id=programming).

## Command Line

### MIT - Missing semester

The Missing Semester of Your CS Education. Practice using development tools while learning to program, and turn the steps you follow into repeatable notes.

### Shell

Use The Art of Command Line alongside The Shell Scripting Tutorial. Practice combining commands, handling input and output, and writing scripts, as well as learning command names.

Resources: [Command-line courses and tutorials](ai_map.md?id=command-line).

## Algorithm

### MIT - 6.006 / 6.121

Introduction to Algorithms. Focus on explaining algorithms clearly, analyzing their complexity, and implementing and testing standard algorithms.

### MIT - 6.046J

Design and Analysis of Algorithms. Continue here after the fundamentals, and practice turning design ideas into arguments.

### CMU 15-451/651

Algorithm Design and Analysis. Compare it with other algorithms courses, then choose one edition as your main study path.

Resources: [Algorithms courses and historical editions](ai_map.md?id=algorithm).

## AI

### Harvard - CS50-AI

CS50's Introduction to Artificial Intelligence with Python. Connect algorithms to programming experiments, and record why a particular method suits a given problem.

### Berkeley - CS188

Introduction to Artificial Intelligence. This offers another route through AI fundamentals. Compare it with the other courses in the resource index before choosing.

### CMU - 15-281

Artificial Intelligence: Representation and Problem Solving. Focus on representing problems, methods for solving them, and the conditions under which each method applies.

Resources: [AI courses and labs](ai_map.md?id=ai).

## Machine Learning

### Stanford - CS229: Machine Learning

Focus on connecting mathematical expressions, algorithm implementations, and experimental results. Complete your own derivations and implementations before consulting assignment reference materials.

### Berkeley - CS189/289A

Introduction to Machine Learning. The index includes several course websites. Once you choose a semester, follow the corresponding schedule.

### CMU - 10-315

Introduction to Machine Learning (SCS majors). When comparing CMU's introductory machine learning courses, consult the course-selection guidance retained at the end of the resource index.

### MIT - 6.036

Introduction To Machine Learning. The index includes Fall 2020 OCW and Open Learning Library resources. Follow one edition consistently.

Resources: [Machine learning courses](ai_map.md?id=machine-learning) · [CMU course-selection guidance](ai_map.md?id=how-to-choose-an-intro-ml-course-at-cmu).

## Deep Learning

### Berkeley - CS182/282A

Deep Neural Networks. The index includes courses and videos from both Spring 2023 and Fall 2023. Use materials from the same semester together.

### CMU - 11-485/785

Introduction to Deep Learning. Focus on model training, recording experiments, and analyzing results.

### CMU - 10-417/617

Intermediate Deep Learning. After completing the fundamentals, explore more advanced topics according to the course requirements.

Resources: [Deep learning courses, videos, and historical editions](ai_map.md?id=deep-learning).

## Computer Vision

### CMU - 16-385

Computer Vision. Use example images to understand vision problems and connect basic concepts with practical processing steps.

### Michigan - EECS 498.008 / 598.008

Deep Learning for Computer Vision. The index retains the Winter 2022 course and existing video links. Check the edition years when using these resources.

Resources: [Computer vision courses and labs](ai_map.md?id=computer-vision).

## Advanced

After choosing a topic, make your learning goal concrete: complete a small project, reproduce an experiment, or write out a method's derivation clearly.

Resources: [Advanced ML roadmap](ai_map.md?id=advanced).

## More

Python for Everybody (PY4E) offers a supplementary programming route. Deep Learning Drizzle helps you find further machine learning materials. Resource discovery links are collected under [More](ai_map.md?id=more).

## UC Berkeley

### CS 88 / DATA C88C: Computational Structures in Data Science

Consider this course for computational foundations relevant to data science. See [UC Berkeley](ai_map.md?id=uc-berkeley) for resources; that section also retains guidance on using the CS61B course website.

## MIT

### MIT - 6.100B (formerly 6.0002)

Introduction to Computational Thinking and Data Science. Continue here after introductory programming and follow the 6.100A+B course schedule.

### MIT - 6.100L (formerly 6.0001, full semester version of 6.100A)

The full-semester edition of Introduction to CS and Programming using Python. Compare it with the half-semester edition and choose the pace that suits you.

Resources: [Additional MIT courses](ai_map.md?id=mit).

The CMU Artificial Intelligence, MIT Course 6-4, and Course 6-3 curricula help explain how courses fit together. When using them for independent study, record completed courses, your current studies, and goals for the next stage separately.
