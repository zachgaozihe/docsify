## 3. SQL 入门 - **w2**

##### 本主题内容

- SQL 背景简述
- 将 SQL 理解为命题（“事实陈述”），而不仅是创建和填充表
- 声明式编程与命令式编程

- **学习成果：**
  - 理解后续（My）SQL 课程的背景，内容包括：
    - 创建表、主键与外键、UPDATE、DELETE、SELECT、JOIN、WHERE 子句、别名、子查询和函数使用
  - 理解编程范式的差异，以及这些差异如何影响 SQL 的写法
  - 了解 MySQL 实现 SQL 时存在的一些不一致之处

## 4. 关系模型 - **w2**

##### 本主题内容

- 数据库与数据模型的类型：层次、网状、关系
- 关系模型的起源
- 关系模型的关键特征，例如关系、属性和键
- 键作为关系模型的独特驱动因素
- 关系模型的参照完整性

- **学习成果**：
  - 理解关系型数据库与其他数据库范式的区别
  - 理解关系与关系模型的基本结构组成
  - 理解键为什么对关系模型至关重要，以及键与 JOIN 的关系
  - 理解键对数据完整性的影响

## 7. SQL 基础、SELECT 与 JOIN - **w3**

##### 本主题内容

- 创建表
- 数据类型
- SQL 约束
