## 管理设置与历史资料

当前 GitHub 连接可提交文件和更新分支，但没有修改仓库默认分支及 Pages 管理设置的工具；本机也没有可用的 GitHub 管理登录凭证。管理员需在 **Settings → General → Default branch** 将 `develop` 改为 `main`。日常更新按根 README 使用 `main`，Pages 来源保持 `main` / `/docs`。

本次从当前分支和发布目录删除了课程网页导出及加入信息。**历史提交仍可能包含原始文件**；分支快进同步不会清除历史。本次没有重写公共 Git 历史或强制推送。未验证旧会话字段和课程加入码是否仍有效；若加入码仍有效，需要课程管理者更换，历史清理应单独处理并考虑其他克隆或缓存副本。

## 后续维护

根 README 是操作说明；`docs/README.md` 是网站首页。每次改文章同步侧栏，运行检查后发布并复查；每月检查常用外链，每季度集中检查依赖和整理重复资料。新增转载注明来源、日期及本站整理说明；校内资料公开前确认适合公开，不保存带账户状态的网页快照。
